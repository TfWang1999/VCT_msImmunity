## 主队列采样范围

CRC 拟合只调整 `r_C、d_0、lambda_0、p_1`，有抗 PD-1 给药的病例再调整 `p_2`；其他模型参数在八例间共同固定。虚拟患者以原始群体分布为基础，使用下表中的治疗参数范围及免疫参数 Beta 情景，不将全部先验均值重新缩放到 CRC 默认值。CRC 中固定一个参数与虚拟群体允许该参数变异是不同设置。

| 参数 | 虚拟患者名义范围 | Beta 形状 |
| --- | ---: | ---: |
| `r_C` | 0.25–0.42 天⁻¹ | (4,3) |
| `C_max` | 5e10–1e11 cell | (6,4)，原始范围 |
| `lambda_T8、lambda_Th` | 5–200 | (2,4)，偏向小值 |
| `lambda_T8h、lambda_Thh`（代码 `TSM.T8h、TSM.Thh`） | 0.15–2.00 | (2,4)，偏向小值 |
| `p_L、p_h` | 1e-9–1e-7 | (1,6)，偏向小值 |
| `d_0` | 0.10–0.35 天⁻¹ | (2,3) |
| `lambda_0` | 0.10–0.40 天⁻¹ | (2,4) |
| `p_1` | 1–10 | (1,2) |
| `p_2` | 1e3–1e6 nM⁻¹ | (1,6)，线性尺度，偏向小值 |
| `K_IL12` | 0.08–1.00 | (4,2)，偏向大值 |
| `K_IL2` | 0.01–0.30 | (4,2)，偏向大值 |
| `q_A` | 5–60 nM | (2,3) |
| `lambda_F` | 0.10–1.00 | (2,3) |
| `lambda_P` | 0.625–3.125 | (2,4) |
| `rho_F` | 0.05–0.15 | (2,3) |

`d_0、lambda_0` 范围覆盖最终 CRC 拟合值；`r_C` 范围覆盖 CRC 的约 0.25–0.367 天⁻¹，并保留较高增殖率的个体。三个化疗耦合系数在 CRC 中固定为 `lambda_F=0.5、lambda_P=1.5625、rho_F=0.1`，虚拟患者的原始先验分别按 0.5、1/32、0.5 倍缩放，保留原有相对宽度和 Beta 形状。其余未列出的分布保持原始设定，完整名义范围和实际抽样值见 `input_data/vct_parameter_design.csv`。

当前免疫参数情景改变四项 T 细胞募集/扩增系数、`p_L、p_h、p_2、K_IL12、K_IL2` 的 Beta 形状，各项上下限保持不变。四项 λ 偏小会减弱相应的 T 细胞募集或扩增。物理尺度上 `rho_L=p_1*p_L`、`rho_h=p_1*p_L*p_h/K_P`、`rho_8=p_1*p_L*p_8/K_P`，随后按细胞尺度无量纲化。因此通过 `p_L、p_h` 偏小使派生的 ρ 偏小，不给 ρ 另设独立 Beta 分布，也不改变这些推导关系。降低这组 ρ 可减轻检查点抑制，与降低 λ 的作用相互抵消，不能把所有参数偏小都解释为免疫效应减弱。

`p_2` 越小，`p_2*A(t)` 介导的检查点抑制解除越弱；`K_IL12、K_IL2` 越大，IL-12/IL-2 对 T 细胞的激活越弱。它们的理论采样均值分别约为 `1.44e5、0.693、0.203`。`K_P` 以及 IL-10/TGF-β 等抑制性信号的半饱和参数保持原设定，因为增大这些参数的作用方向不同。共同免疫参数同时用于四种方案，而非只修改含抗 PD-1 的患者。

每次给药的 `q_F=2.9928`、`q_P=0.50580 μg/mL` 共同固定；`q_A` 表示每次抗 PD-1 给药引起的肿瘤部位有效浓度增量，直接按 `q_A = 5 + 55 × Z`（nM）采样，其中 `Z ~ Beta(2,3)`。`C0/C_max` 在 0.30–0.60 内分层均匀采样，每类免疫细胞初值为 1e6，四种方案使用同一患者参数及初始状态。实际药物浓度随给药和消除变化，药代效应网格为 2.5 分钟。

主队列用 MATLAB Twister 种子 12345 生成。对 76 个参数分别置换分层概率坐标，再按各自的 Beta 逆累积分布函数映射到指定范围。初始肿瘤比例使用种子 12346 单独抽样。当前复现直接读取已保存的设计。Beta 分布定义模拟人群的异质性，全部 1,000 名患者纳入四种方案的模拟和评分。

## 动态药代与重用患者设计

`run_virtual_cohort()` 使用已保存的参数矩阵和初始肿瘤比例，重算同一批患者并保存到 `results/cohort/`。输入治疗矩阵列为 `[day, RT, Cap, Oxa, antiPD1]`：Cap 表示当天口服两次，Oxa/antiPD1 仅在给药日为 1，四方案给药日对应 Supplementary Data.xlsx Table4 的第 1、22、43 天；不再将持续药效记为每天给药。

`Quantify.m` 对动态化疗死亡、增殖抑制和 PD-1 阻断函数取时间平均。molsImmunity 对两种分子药效分数的乘积取平均；tsImmunity 保留 0.5 分子近似，并按有口服化疗或铂输注的日数占比加权，避免把分子浓度响应混入组织尺度指标。无药情况下药效为零。

评分原则保持不变：msImmunity 的分子为分子调控后的 CD8/Th 免疫效应加平均放化疗死亡效应，分母为 `r_C-d_C-平均化疗增殖抑制`。分析入口读取每名患者保存的参数，重新计算无量纲系数和动态药效；不会用单一默认值替代该患者的 `r_C、C_max、d_0、lambda_0、p_2` 或其他采样参数。ODE 与评分共用 `calculate_multiscale_scaling.m` 生成药代浓度和药效，`lambda_F、lambda_P、rho_F` 的新取值同时进入两者。

药代参数是固定的文献参考与降阶假设，未使用临床或小鼠浓度时间序列估计。超滤铂的一室近似不等于原形奥沙利铂药代。
